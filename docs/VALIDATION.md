自行准备原厂 EG 后显式设置环境变量。不要提交该文件或任何产生的输出。

~~~powershell
$env:Z8_STOCK_EG = 'D:\private\original-eg.bi'

~~~

~~~sh
Z8_STOCK_EG=/private/original-eg.bi python -m unittest discover -s tests -v
~~~

## ARM 检查如何工作

Unicorn 加载用户提供的固件指令，运行初始化的 18 次资源复制（其中 16 次属于 B/C/D/E）。复制 API 使用有界 memcpy 桩；没有宣称执行其完整原厂内部实现。

测试确认：
- B/C/D/E ROM/RAM 的 16 段连续映射；
- 整个 261120 字节 PCM 在 RAM 内与预期逐字节一致；
- B 主段和前段均从池首读取整池；
- B/C/D/E 的 16 个地址/长度组合均留在原池内；
- 三段原始 cap 代码，各执行 cap=0、66、340、1000、2000，共 15 个检查；
- 帧数减一为 65279，数值上可放入 16 位，但这不构成真实音频硬件路径已验证的结论。

cap=0 的片段测试不代表真实单拍一定传 cap=0。非零 cap 仍会裁短，实际模式的值需要观察。

## 仍需要的证据

完整相机模拟启动、设置/拍摄/回放/关机和重复触发；实际音频输出的采样或录音；不同快门时间、模式及状态切换的行为。
模拟器没有相应模型时应记录“无法验证”，不能用菜单出现、WAV 试听或无异常日志替代真实输出。
